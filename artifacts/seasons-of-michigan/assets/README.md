# Exhibit image

`seasons-of-michigan.png` is the finished, titled image credited **SimpleMindsStudios - Brad Devowe**. Its original PNG bytes are preserved; this presentation does not replace the artwork with a newly generated or cropped version.

See `../artifact.json` for dimensions, SHA-256, contribution roles, and composite provenance. Preserve the on-image title and credit and all applicable source-photo rights.

`originals/` contains the four source JPGs used in the **How it began** gallery. Each is a byte-identical copy of the file supplied by Brad. `originals/sources.json` preserves the mapping to the original filenames and their checksums; the photographer is not inferred from a filename.
